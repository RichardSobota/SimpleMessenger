# SimpleMessenger
Simple messenger applikácia podobná (veľmi zednodušenému) Twitteru.

Na vytvorenie aplikácie som použil nástroj Kiro (od firmy Amazon), keďže mám s ním ako s jediným spomedzi podobných nstroov nejaké praktické skúsenosti. Nástroj umožňuje použiť buď vibe-coding alebo spec-driven coding. Vybral som si druhú možnosť, pretože vibe-coding považuem za spôsob vhodný na rýchly návrh nejakého prototypu, nie na návrh serióznej aplikácie pre produkčné prostredie.
