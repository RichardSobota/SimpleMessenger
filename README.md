# SimpleMessenger
Simple messenger aplikácia podobná (veľmi zjednodušenému) Twitteru.

Na vytvorenie aplikácie som použil nástroj Kiro (od firmy Amazon), keďže mám s ním ako s jediným spomedzi podobných nástrojov nejaké praktické skúsenosti. Nástroj umožňuje použiť buď vibe-coding alebo spec-driven coding. Vybral som si druhú možnosť, pretože vibe-coding považujem za spôsob vhodný na rýchly návrh nejakého prototypu, nie na návrh serióznej aplikácie pre produkčné prostredie.
Generovanie výsledných zdrojových súborov mi nezbehlo kompletne kvôli vyčerpaným tokenom. :-(
